# Audio-project
It is my first real project with LLM. Just for my learning.

1. AI 실시간 오디오 왜곡 가이드 (가칭: SoundMask)
현대인들의 프라이버시를 극단적으로 지켜주는 온디바이스 AI 보안 앱입니다. 카페나 대중교통 등 공공장소에서 전화를 받거나 대화를 할 때, 주변 사람들에게 내 목소리가 들리지 않거나 완전히 다른 소리로 필터링되어 들리게 만듭니다.

기가 막힌 원리: 모바일의 마이크와 AI 모델을 활용합니다. 내가 말을 하면 이어폰(또는 스마트폰 스피커)을 통해 주변에 내 목소리의 주파수를 상쇄하는 역위상 음파(Active Noise Canceling의 역발상)를 미세하게 쏘거나, 주변 소음과 완벽히 융합되는 백색소음으로 실시간 변조해 출력합니다. 정작 전화를 받는 상대방에게는 AI가 내 목소리만 깔끔하게 추출하여 선명하게 전달합니다.

AI 활용 포인트: 실시간 Voice Isolation 및 오디오 도메인에서의 주파수 상쇄 예측 모델을 모바일 기기 내에서 초저지연(Low Latency)으로 구동(On-Device AI)해야 하므로 기술적 난이도와 독창성이 엄청납니다.
